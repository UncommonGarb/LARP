# Future Enhancements

## Character Discovery (Discover Tab)
- In the future, if we expand the "Discover" tab to pull from a network or online hub rather than just local characters, we should add Shared Element Transitions (Hero animations) where tapping a character card in the grid smoothly scales the character's avatar up into the Character Detail Screen header image.
- Currently, since characters are locally managed (created or imported by the user), the "Discover" feed acts more like a local "Home" library.
